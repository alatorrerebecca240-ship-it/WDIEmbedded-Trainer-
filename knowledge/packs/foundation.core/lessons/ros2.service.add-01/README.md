# 请求生成响应

这是普通 C++ 请求/响应函数练习，用来理解 ROS 2 服务的数据流。不包含真实 ROS 2 服务端、客户端、执行器或网络通信，无需安装 ROS 2。

## 要求

实现 `AddResponse handle_add(const AddRequest &request)`。

- 请求含 std::int64_t 类型的 a 与 b，响应含同类型的 sum。
- 返回的 sum 必须等于 a + b，保持请求不变。
- a、b 均在 [-1000000000000, 1000000000000] 内，保证求和不会超出 int64_t 范围；不要转成 int 等较窄类型。
- 不需要分配内存、打印答案或创建 main，不修改头文件。

示例：请求 {7, -3} 返回 {4}；请求 {0, 0} 返回 {0}。

测试覆盖正数、负数、零、相消和超出 32 位整数范围的输入。以后接入真实 ROS 2 时，还需声明 .srv 接口并把类似处理逻辑放入服务回调；本题的函数签名不是 rclcpp 的完整回调接口。
