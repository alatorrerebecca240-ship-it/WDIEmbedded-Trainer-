# 游程编码与解码

将连续重复字符压缩为计数加字符的形式，并能恢复原始文本。

知识点：字符串、循环、计数、多位数字解析

## 题目要求

实现 `run_length_encoding::encode` 和 `decode`。

编码时，只合并相邻且相同的字符：出现两次及以上写为“次数 + 字符”，只出现一次则省略次数 1。保留大小写区别和空白字符。

解码时，数字表示紧随其后字符的重复次数；计数可能有多位。没有数字前缀表示出现一次。编码前的输入只包含英文字母（大写或小写）和空白，不含数字，因此无需解决“原始数字与次数”的歧义。

## 示例

```text
AABCCCDEEEE -> 2AB3CD4E -> AABCCCDEEEE
```

连续 12 个 `W` 后接一个 `B`，编码为 `12WB`。`AAaa` 编码为 `2A2a`，不能合并成 `4A`。空白也是数据，不能在解码前全部删除。

## 提示

- 编码时记录当前字符及连续数量，在字符变化时输出上一组。
- 循环结束后不要漏掉最后一组。
- 解码时先累计所有连续数字，再展开下一个字符。
