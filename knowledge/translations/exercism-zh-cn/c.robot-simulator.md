# 机器人运动模拟

解析转向和前进指令，更新机器人在二维网格上的位置与朝向。

知识点：结构体、枚举、字符串遍历、状态更新

## 题目要求

机器人位于无限大的二维整数网格上，朝向北、东、南、西之一。向东移动使 `x` 增大，向北移动使 `y` 增大。

- `R`：原地向右旋转 90 度。
- `L`：原地向左旋转 90 度。
- `A`：沿当前朝向前进一步。

实现 `robot_create(direction, x, y)` 创建初始状态，实现 `robot_move(robot_status_t *robot, const char *commands)` 按字符串顺序修改状态。使用头文件中给定的结构体与方向枚举。

## 示例

机器人从 `(7, 3)` 朝北出发，执行 `RAALAL`：先右转朝东，前进两步到 `(9, 3)`，左转朝北，前进一步到 `(9, 4)`，再左转朝西。最终位置为 `(9, 4)`，朝西。

## 提示

- 将“改变方向”和“改变坐标”分开处理。
- 左转越过北方时要回到西方，注意 C 中负数取余的行为。
- `robot_move` 接收指针，应修改指针指向的机器人状态。
