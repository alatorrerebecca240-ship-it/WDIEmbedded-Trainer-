# 三进制转十进制

根据位权，自行将只含 0、1、2 的三进制文本转换为整数。

知识点：进制转换、字符串、循环、输入校验

## 题目要求

实现 `trinary::to_decimal`，不使用现成的进制转换函数。

三进制只有 `0`、`1`、`2` 三种数字。从右到左位权依次为 1、3、9、27……。输入含其他字符时，整个结果为 0，不能只保留非法字符之前的转换结果。

## 示例

```text
102012
= 1×3⁵ + 0×3⁴ + 2×3³ + 0×3² + 1×3¹ + 2×3⁰
= 243 + 0 + 54 + 0 + 3 + 2
= 302
```

`10` 转换为 3，`123` 因含非法数字 3 而返回 0。

## 提示

- 可从左到右使用“已有结果乘以 3，再加当前位”。
- 检查字符合法后，再减去字符 `0` 得到数值。
- 数学中的幂符号不是 C++ 中的 `^` 运算符。
