# 统计 DNA 碱基数量

统计 DNA 字符串中 A、C、G、T 四种字符的出现次数。

知识点：字符串视图、映射容器、计数、异常处理

## 题目要求

本题无需生物学知识，只需把 DNA 看作由四种大写字母组成的字符串。实现 `nucleotide_count::count(std::string_view dna)`，返回 `std::map<char, int>`。

结果应包含 `A`、`C`、`G`、`T` 四个键；未出现的碱基计数为 0。输入中只允许这四种字符，出现其他字符时，应按本包接口抛出 `std::invalid_argument`，不能默默跳过或转换为大写。

## 示例

- `GATTACA` → `A: 3, C: 1, G: 1, T: 2`。
- 空字符串 → 四种计数均为 0。
- `INVALID` → 非法输入，应报告错误。

## 提示

- 先将四种计数初始化为 0，再逐个字符累加。
- 检查字符是否属于合法集合后再更新计数。
- 注意映射的下标操作可能自动插入不存在的键。
