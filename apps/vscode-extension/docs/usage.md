# Embedded Trainer 使用说明

Embedded Trainer 用于在 VS Code 内学习和评测 C、C++、嵌入式、智能车、电子设计竞赛、Linux 和 ROS 2 基础课程。正常训练不需要手动打开终端或输入命令。

## 界面组成

- **活动栏 Embedded Trainer 图标**：打开课程路线。
- **课程路线**：先按学习方向，再按编程题、选择题、判断题和填空题分组。
- **课程详情面板**：阅读题目、提交答案、打开代码、运行评测和查看分级提示。
- **测试资源管理器**：运行单道或全部编程题。
- **问题面板**：显示编译错误和警告，点击可跳转到源码。
- **状态栏 Trainer 进度**：显示“已通过题数/题目总数”。
- **Embedded Trainer 输出**：保留完整后台评测日志，仅在排查问题时查看。

### 0.7.0 原生风格工作台

- 保留 VS Code 原生课程树，每条路线和题型显示题目数、已通过数；刷新时保留分组展开状态。
- 课程面板采用紧凑布局，题目、作答与评测结果在主区域，学习状态、知识点、前置课程与知识包版本在右侧。分屏较窄时，信息区自动移到下方。
- 顶部常驻“知识包”和“使用说明”，编程题的主要按钮会从“开始练习”切换为“运行评测”。
- 细线、冷色强调和等宽编号提供轻微的科幻感；背景、按钮和文字跟随 VS Code 主题，兼容浅色、深色和高对比度，没有闪烁或循环动画。
- 同一面板中查看提示或刷新课程，会保留当前题目尚未提交的答案。切换题目或关闭面板后不保证保留草稿；正式学习进度仍由训练核心保存。
- 可用 Tab 在按钮和输入框间移动，用方向键切换单选项；提交中暂时禁用控件，避免重复请求。

## 第一次使用

1. 本项目用户继续打开项目根目录；新电脑也可以打开任意练习文件夹，插件已内置训练核心。
2. 点击活动栏中的 Embedded Trainer 图标。
3. 展开“C 语言基础”，再展开需要的题型。
4. 点击题目名称，在编辑区的课程面板中作答。

插件在后台调用训练核心，不会创建 PowerShell 终端。

当前有七条路线、共 198 题，包含 C 语言基础、C++ 基础、嵌入式基础、智能车竞赛、电子设计竞赛、Linux 基础和 ROS 2 基础。每条路线都具有编程题、选择题、判断题和填空题，并以入门题为主。

## Linux 与 ROS 2 基础怎么学

- 在课程树展开“Linux 基础”或“ROS 2 基础”，每条有 32 题：2 道编程、12 道选择、9 道判断、9 道填空。
- 先做入门知识题，再做配套编程，最后尝试标为“进阶”的题目；每道题都有提示与答对后的解析。
- Linux 命令知识以 Linux Bash/GNU 工具为前提，不能直接当作 PowerShell 命令使用。建议按路径 → 文件 → 权限 → 管道/重定向 → 环境与进程的顺序学习。
- ROS 2 内容以 Jazzy 入门文档为参考。建议按节点 → 话题/消息 → 服务/动作 → 参数 → 工作空间 → QoS/tf2 的顺序学习；这不是指定你必须安装 Jazzy。
- 标为“基础知识”的题目仅检查答案，不执行命令，不要求电脑安装 Linux、WSL 或 ROS 2，但插件后台仍需要 Python。
- 四道配套编程题用普通 C/C++ 模拟权限文本、路径解析、速度消息和请求响应，只依赖现有编译器。它们不测试真实 Linux 系统调用或 ROS 2 通信，不会控制硬件。
- 题干中的 ROS 2 命令假定对应包已安装、终端已加载环境；真正实践这些命令时需要另行搭建匹配环境。
- 更多学习边界与官方资料链接见项目 `content/linux-basics/README.md` 和 `content/ros2-basics/README.md`。

## 完成选择题、判断题或填空题

1. 在课程路线中点击题目。
2. 单选题选择一个选项；判断题选择“正确”或“错误”；填空题填写每一空。
3. 点击“提交答案”。
4. 回答正确后会立即显示解析，并把进度更新为“已通过”。
5. 回答错误时可以重试，也可以点击“查看提示”逐级获得线索。

客观题直接在面板完成，不会创建源码文件。填空题会自动忽略首尾空白；是否区分大小写由题目设置决定。

## 完成编程题

1. 阅读课程目标和知识点，点击“完整题目”确认要求。
2. 点击“开始练习”，插件会把初始代码复制到 `exercises/<课程 ID>/` 并打开源码。
3. 找到代码中的 `TODO`，完成实现。
4. 点击课程面板中的“运行评测”，或使用测试资源管理器的运行按钮。
5. 插件自动保存文件、编译、运行测试并更新进度。
6. 未通过时先看课程面板结果和“问题”面板，再按需查看分级提示。

第一次开始编程题后，你修改的是个人练习副本；知识包和缓存中的源文件不会被覆盖。纠错题操作相同，重点是修复提供的错误实现。代码阅读题在面板显示源码，填写输出后提交，不在学习者电脑自动运行显示的程序。

## 知识包管理

课程树顶部的包图标打开“管理知识包”，也可在命令面板搜索 `Embedded Trainer: 管理知识包`。

- **添加来源、浏览并安装**：填写你信任的 GitHub Pages `catalog.json` HTTPS 地址，再选择需要的包。源码与插件分离，新电脑不必克隆项目。项目公共清单为 [catalog.json](https://alatorrerebecca240-ship-it.github.io/WDIEmbedded-Trainer-/catalog.json)。
- **自动更新**：VS Code 运行期间默认每 24 小时检查一次；可在设置中修改检查间隔或关闭自动更新，也可随时点“检查并更新题库”。关闭 VS Code 后不会常驻后台。
- **离线导入**：选择审核后的 ZIP，粘贴可信来源给出的 64 位 SHA-256。下载错误或校验失败保留旧版，安装过程不执行包内代码。
- **回退**：选择保留版本，回退后自动暂停该包更新，避免下次检查马上升回去；管理菜单可恢复更新。
- **代码信任**：新下载的编程/纠错包首次评测前，先检查来源和源码，再选择“信任知识包代码”。这意味着允许该版本的代码在你的账号下原生运行；SHA-256 本身不能证明安全，新版本需要重新确认。客观题和代码阅读的填答不要求此授权。
- **换电脑**：每台电脑安装 VSIX 和 Python，编程评测再装编译器。启用 VS Code Settings Sync 的设置同步后，可信清单地址和所选包 ID 会同步，插件会下载相同订阅。它不自动同步个人答案、进度、编译器或代码信任。
- **缓存位置**：“打开版本与缓存目录”显示实际本机路径。版本目录不可手工修改，已有练习仍使用创建时缓存的版本；更新不会覆盖 `exercises/`。

未打开文件夹时使用插件私有练习目录；打开工作区时，练习代码在该工作区的 `exercises/`，进度在 `.trainer/progress.json`。本项目当前使用 `knowledge/packs/foundation.core/` 的 198 道题，旧 `content/` 留作兼容。导入和 AI/模板生成的草稿不直接出现在课程树中，必须先审核。

维护者的获取、生成、Actions Docker 审核、GitHub Releases 与 Pages 配置见项目 `docs/knowledge-pack-workflow.md`。普通学习者不需要安装 Docker 或操作发布命令。

## 课程按钮

### 开始练习 / 打开代码

仅用于编程题。第一次点击时创建练习副本，以后点击只会打开已有代码，不会重置答案。

### 运行评测

仅用于编程题，流程为：

```text
保存当前文件 → 调用编译器 → 运行自动测试 → 更新进度 → 展示结果
```

初始代码能编译但测试失败是正常状态，完成实现后应变为绿色通过。

### 提交答案

用于选择题、判断题和填空题。正确后显示知识解析，错误时不会提前泄露答案。

### 查看提示

提示按信息量递增。建议从提示 1 开始，避免过早看到接近答案的信息。

### 完整题目

编程题会在编辑区打开 Markdown 说明；客观题的完整题干已经显示在课程面板中。

## 使用测试资源管理器

点击活动栏中的烧杯图标打开“测试”。Embedded Trainer 只把编程题放入这里：

- 点击题目旁的运行按钮，只评测这一题。
- 点击顶层运行按钮，依次评测全部编程题。
- 展开运行记录可查看完整编译及测试输出。

运行尚未开始的编程题时，插件会先自动创建练习副本。

## 查看学习进度

点击状态栏中的 `Trainer 已通过数/总数`，或点击课程视图顶部的进度图标。进度分为：

- **未开始**：尚未提交答案或开始编程练习。
- **进行中**：已经作答，但最近一次未通过。
- **已通过**：最近一次提交或评测通过。

进度保存在项目的 `.trainer/progress.json`，不会上传到网络。

## 常见问题

### 课程列表为空

本项目用户确认打开的是项目根目录；新电脑可打开任意练习文件夹，从面板或课程树顶部进入“管理知识包”，添加可信来源并安装题库。若仍为空，检查 Python 配置，并查看“Embedded Trainer”输出中的刷新错误。

### 新题目没有出现

点击课程视图顶部的刷新按钮。若刚更新过插件，按 `Ctrl+Shift+P` 执行“开发人员: 重新加载窗口”。

### 点击评测后提示找不到 Python

打开 VS Code 设置，搜索 `Embedded Trainer Python Path`，填写 Python 可执行文件的绝对路径。

### 提示找不到 C 或 C++ 编译器

需要安装 GCC 或 Clang，并确保 VS Code 可以找到它；也可以使用项目提供的 Dev Container。

### 如何再次打开本说明

- 点击课程视图顶部的问号图标。
- 在课程详情面板点击“使用说明”。
- 从命令面板执行 `Embedded Trainer: 打开使用说明`。

## 内容位置

- `knowledge/packs/`：本项目的知识包源码；普通练习不直接修改。
- `content/`：保留的旧版课程源，供兼容使用。
- `exercises/`：编程题的个人练习代码。
- `.trainer/`：本机进度和临时构建结果。
- `docs/adding-a-lesson.md`：为题库作者准备的扩展说明。
