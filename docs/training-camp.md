# 新生训练营第一版

本版在同一个 `local-development.embedded-trainer` 插件中增加路线层，不重写引擎，不迁移题目，不改变执行信任或已发布知识包。

## 学习者

点击侧边栏“新生训练营 · 路线图”。主线包含七个能力阶段和 49 道必做题，没有周次、截止时间或强制锁定；选做题不阻塞主线。展开阶段后依次阅读概念、预测示例、完成练习、记录自查。顶部“继续学习”优先返回上次从路线打开但未通过的必做题。

“完整题库”继续包含现有各学科题目。题目面板新增返回路线入口；提示按层逐步展开，原题提示保持原文，前后增加需求分析和验证引导，不自动展示参考答案。

题目进度仍保存在 `.trainer/progress.json`。训练营自查独立保存在 `.trainer/camp-progress.json`，不会覆盖旧成绩。主线阶段标记完成需要必做题全部通过并保存非空自查；这只表示练习与自查完成，不代表已掌握或带教验收。

## 带教与导出

路线页面可导出 Markdown 或 JSON 学习报告。报告包括当前路线版本、题目状态、提交次数和学习者自查文字；不自动收集代码、账号和绝对路径，也不上传。学习者可能自行在文字中填入私人信息，所以分享前应检查。

综合项目指南是人工实践与讲解任务，不伪装成已有自动评分项目。带教同学应检查输入输出记录和现场解释。

## 扩展路线，不复制题目

点击“导出路线模板”，在目标工作区根目录保存为 `trainer-roadmap.json`。插件会使用该文件代替内置路线；题目仅通过稳定 ID 引用。可以增删阶段、调整必做与选做、修改讲解和自查任务，不需要重新发布题库或修改插件代码。

字段格式见 `schemas/training-route.schema.json`；内置样例位于 `apps/vscode-extension/routes/lab-foundations.json`。单文件上限 256 KB，最多 30 个阶段，每阶段至多 100 道引用，路线内题目 ID 不重复。引用缺失时明确显示“未安装”，不会悄悄算通过。可通过“管理知识包”安装需要的包。

修改教学目标或自查要求时递增路线 version；旧自查文字保留，但旧版本确认不自动当作新版确认。题目原成绩继续沿用。第一版不提供账号系统、自动排名、教师后台、项目自动评分或远程记录汇总。

## 性能和兼容

路线读取现有内存目录和成绩，不额外启动 Python、不重新扫描整个题库、不执行课程代码。自查写入串行化，使用原子替换；同一路线的未保存输入保留在 Webview 状态中。损坏的自查文件不会被重置覆盖，也不会阻止原题目评测。

训练营版安装包版本为 0.11.0，知识包引擎兼容版本仍是 0.10.1。新旧版插件身份相同；单独使用经典版时，应使用不同 VS Code 配置文件安装备份的 0.10.1 安装包，而不是尝试在同一配置文件并存两个版本。
