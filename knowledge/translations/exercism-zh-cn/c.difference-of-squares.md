# 平方和与和的平方

计算前 n 个自然数的平方和、和的平方，以及两者之差。

知识点：循环、算术运算、函数

## 题目要求

这里的前 n 个自然数指 `1, 2, …, n`。实现头文件中的三个函数：

- `sum_of_squares(number)`：每个数分别平方后相加。
- `square_of_sum(number)`：先把所有数相加，再对总和求平方。
- `difference_of_squares(number)`：和的平方减去平方和，注意减法方向。

## 示例

当 n 为 10 时：

```text
和的平方：(1 + 2 + … + 10)^2 = 55^2 = 3025
平方和：  1^2 + 2^2 + … + 10^2 = 385
差值：    3025 - 385 = 2640
```

可以先用循环写出清晰的实现，也可以查阅求和公式再进行优化。原题允许查资料，不要求凭空推导最高效算法。题面的幂记号不能直接当作 C 的 `^` 运算符使用。

## 提示

- 两个名称相近的函数，运算顺序却不同，可以先手算 n 为 3 的情况。
- 三个函数应使用相同的取值范围约定。
- 留意乘法的中间结果和返回类型范围。
