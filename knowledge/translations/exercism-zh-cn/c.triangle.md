# 判断三角形类别

根据三条边长，判断是否为等边、等腰或不等边三角形。

知识点：条件分支、结构体、浮点数、逻辑运算

## 题目要求

使用 `triangle_t` 中的 `a`、`b`、`c`，分别实现：

- `is_equilateral`：三条边都相等。
- `is_isosceles`：至少两条边相等，因此本题的等边三角形也属于等腰三角形。
- `is_scalene`：三条边两两不相等。

分类前先检查边长有效性：每条边必须大于 0；任意两边之和不能小于第三边。

```text
a + b >= c
b + c >= a
a + c >= b
```

两边之和恰好等于第三边称为退化情况，例如 `(1, 1, 2)`。上游原题明确不测试退化三角形，可自行决定如何处理；不要将其与普通三角形的严格几何定义混淆。

## 示例

`(3, 3, 3)` 是等边且等腰；`(3, 3, 4)` 是等腰；`(3, 4, 5)` 是不等边；存在零边长或明显违反三角不等式时，不能归入上述类别。

## 提示

- 把有效性检查提取为共用辅助函数，避免三处重复。
- “至少两边相等”可以用多个相等条件之间的逻辑或表达。
- 边长是 `double`，不要强制转换为整数后比较。
