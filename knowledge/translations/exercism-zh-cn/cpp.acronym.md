# 提取首字母缩写

识别短语中的单词边界，组合各单词的大写首字母。

知识点：字符串、字符处理、条件分支

## 题目要求

实现 `acronym::acronym`，将英文短语转换为缩写。例如 `Portable Network Graphics` 得到 `PNG`。

空白和连字符 `-` 都是单词分隔符；其他标点可以从输入中移除，而不是一律当作新单词的起点。结果字母使用大写。

| 输入 | 输出 |
| --- | --- |
| `As Soon As Possible` | `ASAP` |
| `Liquid-crystal display` | `LCD` |
| `Thank George It's Friday!` | `TGIF` |

其中 `It's` 的撇号不产生一个新单词。

## 提示

- 可用一个布尔变量记录“下一个字母是否为单词首字母”。
- 分清分隔符与仅需忽略的标点符号。
- 使用字符分类函数时，注意传入值的有效范围。
