# 判断阿姆斯特朗数

拆分十进制数位，判断各位数字的指定次幂之和是否等于原数。

知识点：循环、数位分解、整数运算

## 题目要求

一个有 n 位数字的数，如果等于它的每一位数字的 n 次幂之和，就称为阿姆斯特朗数。编写 `is_armstrong_number(int candidate)` 判断输入是否满足这个定义，返回布尔值。

## 示例

- `9` 满足：`9 = 9^1`。
- `10` 不满足：`1^2 + 0^2 = 1`，不等于 10。
- `153` 满足：`1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`。
- `154` 不满足：`1^3 + 5^3 + 4^3 = 190`。

这里的 `^` 是题面中的数学幂记号，不是 C 语言的幂运算符。注意单个数字以及 0 的处理，不要在逐位分解时丢失用于最后比较的原始输入。

## 提示

- 先确定十进制位数，再按相同位数计算每一位的幂。
- 取余和整数除法可以逐次取出末位数字。
- 检查 0、单个数字和多位数；最后比较的是累加结果与原数。
