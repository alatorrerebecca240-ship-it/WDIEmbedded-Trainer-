# 统计二进制中的 1

根据鸡蛋位置的二进制编码，统计其中实际有多少个鸡蛋。

知识点：位运算、循环、二进制

## 题目背景

鸡舍把各个位置编码成一串二进制位：有鸡蛋的位置记为 1，空位置记为 0；显示屏把这串二进制数换成十进制显示。Eliud 希望直接知道鸡蛋总数，而不是位置编码。

## 题目要求

实现 `unsigned int egg_count(unsigned int value)`，统计输入整数的二进制表示中有多少个 1。

必须自己实现计数，不要使用标准库或编译器已经提供的位计数功能代替核心算法。

## 示例

```text
位置编码：1 0 1 1 0 0 1
十进制：89
鸡蛋数：4

位置编码：0 0 0 1 0 0 0
十进制：8
鸡蛋数：1
```

前导零不影响鸡蛋数量。输入 0 表示所有位置都没有鸡蛋，返回 0。上面的文字图完整表达原题示例，离线时不需要加载外部图片。

## 提示

- 可以检查最低位，再把其余位移到低位继续处理。
- 别把十进制数字中 1 的个数误当成二进制位中 1 的个数。
- 检查 0、只有一个置位的数，以及多个连续置位的数。
