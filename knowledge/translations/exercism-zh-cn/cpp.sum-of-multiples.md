# 求指定倍数的总和

找出小于上限且为任意给定因子倍数的数，去重后求和。

知识点：循环、取模运算、集合、去重

## 题目要求

实现 `sum_of_multiples::to(multiples, num)`。参数 `multiples` 给出若干基数，`num` 是不包含在结果中的上限。

对每个基数找出小于上限的倍数，合并并去重，再求和。同一个数即使是多个基数的倍数，也只能计算一次。

## 示例

基数为 3 和 5，上限为 20：

- 3 的正倍数：3、6、9、12、15、18。
- 5 的正倍数：5、10、15。
- 合并去重：3、5、6、9、10、12、15、18。
- 总和为 78；15 不能重复计算，20 不包含在内。

## 提示

- 可以枚举候选数，只要匹配一个基数就累加一次。
- 也可以枚举各基数的倍数，用集合去重。
- 若处理值为 0 的基数，必须避免除以 0 或以步长 0 循环。
