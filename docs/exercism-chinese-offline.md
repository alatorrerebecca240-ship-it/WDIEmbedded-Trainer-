# 50 道 Exercism 中文离线更新

本次将已发布的 26 道 C 和 24 道 C++ 题中文化。每个知识包从 1.0.0 更新为 1.0.1，包 ID 与题目 ID 不变。不是新增另一组重复题，也不改插件或基础课程合集。

## 内容位置

- 中文源稿：`knowledge/translations/exercism-zh-cn/*.md`。
- 专用构建与同步脚本：`scripts/localize-exercism.py`。
- 数据验证测试：`tests/test_localization.py`。
- 本地输出：`dist/Embedded-Trainer-Exercism-50-zh-CN-1.0.1-offline.zip`。

源稿包含标题、摘要、知识点、题目说明及最后的提示列表。构建时将提示提取到题目元数据，避免题干提前展示全部提示；旧英文题干作为 `README.en.md` 保留。函数名、返回类型、英文结果常量与测试不翻译。

## 构建约束

仅接受已固定 SHA-256 的 `knowledge-v1.1.0/catalog.json` 和其列出的原版 50 个 ZIP。所有包首先经过安全解压、清单完整性和原审核记录检查。

只允许修改标题、摘要、知识点、提示、题干以及明确列出的中文来源说明；包版本和标题相应更新。其余文件和配置必须与原版逐字节一致，包括初始代码、参考答案、测试、编译参数、上游保留文件和许可证。禁止借翻译引入其他程序文件或功能修改。

这是一条**仅限本地离线内容更新**的流程，不改变正常发布的 Docker 验证门槛。当前报告只表示中文内容检查、格式、重复摘要及代码一致性检查通过，没有声称重新编译或执行参考答案。

中文内容复核人明确记为 Codex AI，不冒用原人工审核人，也不把旧 CI 报告的哈希绑定到新版本。原人工审核记录、原包地址及哈希保存在各包 `localization.json`。后续若发布到 GitHub，仍按仓库的正式审核发布流程处理。

## 已标明的原版差异

- 三环电阻：旧 C 参考实现升单位时使用整数除法，原题举例中有不能用整数千欧表示的阻值；现有测试未覆盖该差异。
- 学生年级名单：上游文字要求拒绝重复登记，但旧 C++ 测试和参考实现尚未覆盖该规则。

这两点已经写进对应中文题干，避免学习者误以为“测试通过”代表所有扩展要求都已满足；本次未改动任何测试或参考实现。

## 维护者操作

在项目根目录运行：

```powershell
python scripts/localize-exercism.py build
python -m unittest discover -s tests -p test_localization.py -v
```

构建拒绝覆盖已有输出目录和不同内容的同版本包。若要继续修改内容，请显式规划新版本，不要改写已安装的不可变版本。

同步时显式指定已解压的合集和目标存储目录，例如：

```powershell
python scripts/localize-exercism.py install --bundle "dist/Embedded-Trainer-Exercism-50-zh-CN-1.0.1-offline" --store ".trainer/knowledge"
```

VS Code 使用自己的全局存储目录，不能只更新项目的 `.trainer/knowledge` 就认为插件也完成同步。脚本会先校验所有包，备份 `installed.json`，然后调用现有安装机制。保留旧版本、旧信任记录及学习进度，不调用自动信任操作。

安装过程逐包激活，并不是 50 包的整体原子事务；如果中途异常，已经安装的部分仍有效，修复原因后可重试剩余更新。不要让另一个安装任务同时修改同一存储目录。

## 学习者离线导入

先解压外层合集，在插件“管理知识包 → 离线导入”中选择 `packages` 下的单个 ZIP，并使用对应 `.zip.sha256` 提供的校验值。当前插件按单包导入，外层合集本身不是一个可直接导入的知识包。

同步完成后刷新课程或重新打开题目页面。原有练习副本继续保留，不被中文题库覆盖；在新的课程页面点击“完整题目”查看中文说明。如果提示新版代码尚未获准执行，按插件的知识包授权流程确认。
