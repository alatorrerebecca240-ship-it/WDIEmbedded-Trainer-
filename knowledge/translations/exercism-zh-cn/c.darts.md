# 飞镖计分

根据落点到圆心的距离，计算一支飞镖得到的分数。

知识点：浮点数、条件分支、平面坐标

## 题目要求

靶盘由三个同心圆组成，圆心都是 `(0, 0)`。内圆、中圆、外圆半径分别为 1、5、10。输入 `coordinate_t` 中的实数坐标 `x` 和 `y`，实现 `uint8_t score(coordinate_t landing_position)`。

设落点到原点的距离为 d，按下面的规则计分；恰好落在圆周上时，算作对应圆内。

| 距离范围 | 分数 |
| --- | --- |
| `d ≤ 1` | 10 |
| `1 < d ≤ 5` | 5 |
| `5 < d ≤ 10` | 1 |
| `d > 10` | 0 |

例如，圆心 `(0, 0)` 得 10 分，落点 `(0, 5)` 得 5 分，落点 `(0, 11)` 得 0 分。正负坐标不影响按距离计分的规则。

中文题面用表格表达原图中的完整计分规则，离线时不需要加载外部图片。原英文题中的靶盘图由 habere-et-dispertire 使用 Inkscape 绘制，署名保留在英文原文中。

## 提示

- 距离平方为 `x*x + y*y`；可以比较距离平方与半径平方。
- 从较小的圆向外判断，避免把内圆落点先归入外圆。
- 特别检查半径恰好为 1、5 和 10 的边界。
