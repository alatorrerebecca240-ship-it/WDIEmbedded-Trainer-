# DNA 转录为 RNA

按碱基互补关系，将 DNA 字符串转换为对应的 RNA 字符串。

知识点：字符串、条件分支、动态内存、指针

## 题目要求

DNA 和 RNA 都可以表示为碱基字母组成的序列。本题只练习字符转换，不要求生物学背景。逐个字符按下表替换，保持原有顺序：

| DNA 碱基 | RNA 碱基 |
| --- | --- |
| G | C |
| C | G |
| T | A |
| A | U |

实现 `char *to_rna(const char *dna)`，返回转换后的字符串。输入参数不可修改；返回字符串的存储方式应满足测试对结果的使用和释放要求。

## 示例

`ACGT` 转换为 `UGCA`；空序列转换后仍为空字符串。

## 提示

- 可用 `switch` 或查找表表达四种对应关系。
- 为结果分配空间时，别忘记字符串末尾的 `\0`。
- 不要返回函数内部局部数组的地址；先阅读测试中的 `free` 调用。
