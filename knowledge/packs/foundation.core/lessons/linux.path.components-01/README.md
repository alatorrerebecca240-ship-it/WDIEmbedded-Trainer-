# 统计路径片段

这是标准 C 的字符串练习；输入是 Linux 风格路径文本，但不调用任何 Linux 系统接口，不要求路径真实存在。

## 要求

实现 `size_t count_path_parts(const char *path)`，返回被字符 '/' 分隔的非空片段数量。

- 空指针、空字符串、只有 '/' 的字符串返回 0。
- 连续的 '/' 不产生空片段；忽略开头和末尾的 '/'。
- '.'、'..' 以及含空格的片段都当作普通非空片段计数，不做路径规范化。
- 非空指针保证指向以 '\0' 结尾的有效字符串，不得修改输入内容。
- 不要添加 main，不要修改函数签名。

## 示例

| 输入 | 结果 |
| --- | --- |
| /home/student/src | 3 |
| logs//today/ | 2 |
| / | 0 |
| ./src/../include | 4 |
| my notes/file.txt | 2 |

测试包括空指针、空串、绝对与相对路径、连续分隔符、点片段与空格。
