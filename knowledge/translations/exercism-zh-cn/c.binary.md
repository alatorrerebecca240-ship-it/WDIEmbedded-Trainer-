# 二进制字符串转换

不借助现成进制转换函数，把二进制字符串转换成十进制整数。

知识点：字符串、进制、输入检查

## 题目要求

实现 `int convert(const char *input)`。输入是由字符 `0` 和 `1` 组成的二进制数，例如 `"101010"`，返回对应的十进制数。要识别非法输入；本题头文件使用 `INVALID` 表示非法结果，其值为 `-1`。

转换算法需要自己实现，不要调用已经完成字符串转整数或进制转换的函数来代替核心过程。

## 位权说明与示例

十进制的 `23` 可以写成 `2 × 10^1 + 3 × 10^0`。二进制使用同样的规则，只是底数变为 2：最右一位权重为 1，再向左依次是 2、4、8 等。

因此，`"101"` 表示 `1 × 2^2 + 0 × 2^1 + 1 × 2^0 = 5`；`"101010"` 表示 42。前导零不会改变数值。程序输入仍使用英文数字字符，不要改成中文数字。

## 提示

- 从左往右处理时，读入新的一位之前，已有数值的位权会如何变化？
- 先检查当前字符是否为 0 或 1，再把它当成数字参与计算。
- 留意空串等边界情况，并查看本题测试约定。
