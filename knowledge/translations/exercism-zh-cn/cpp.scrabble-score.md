# 计算单词分数

根据字母分值表，累计一个英文单词的总分。

知识点：字符串、查找表、字符处理、累加

## 题目要求

实现 `scrabble_score::score`。每个字母按下表计分，大写与小写按同一字母处理；重复出现的字母每次都要计分。本题不需要处理棋盘上的额外加倍格。

| 字母 | 分值 |
| --- | --- |
| A E I O U L N R S T | 1 |
| D G | 2 |
| B C M P | 3 |
| F H V W Y | 4 |
| K | 5 |
| J X | 8 |
| Q Z | 10 |

## 示例

`cabbage` 的分数为 `3 + 1 + 3 + 3 + 1 + 2 + 1 = 14`。空单词的总分为 0。

## 提示

- 可以先统一字母大小写，再查询分值。
- 用数组或映射保存分值可以减少冗长分支。
- 本题求总分，不是求出现过的不同字母的分值之和。
