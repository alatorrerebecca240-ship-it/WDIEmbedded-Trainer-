# 三环电阻读数

根据三条色环计算阻值，并用合适的电阻单位表示结果。

知识点：枚举、结构体、整数运算、单位换算

## 题目要求

前两条色环构成两位有效数字，第三条表示乘以 10 的几次方。例如橙、橙、红表示 `33 × 10² = 3300` 欧姆。

| 颜色 | 枚举 | 数字 |
| --- | --- | --- |
| 黑 | BLACK | 0 |
| 棕 | BROWN | 1 |
| 红 | RED | 2 |
| 橙 | ORANGE | 3 |
| 黄 | YELLOW | 4 |
| 绿 | GREEN | 5 |
| 蓝 | BLUE | 6 |
| 紫 | VIOLET | 7 |
| 灰 | GREY | 8 |
| 白 | WHITE | 9 |

实现 `resistor_value_t color_code(resistor_band_t colors[])`。本题 C 接口返回包含 `value` 和 `unit` 的结构体，不是打印一句描述。单位使用头文件中的 `OHMS`、`KILOOHMS`、`MEGAOHMS` 等枚举；相邻单位相差 1000 倍。只读取前三条色环，忽略额外颜色。

## 示例

- 橙、橙、黑：33 欧姆，即 `value = 33`、`unit = OHMS`。
- 红、黑、红：2 千欧，即 `value = 2`、`unit = KILOOHMS`。
- 橙、橙、橙：33 千欧，即 `value = 33`、`unit = KILOOHMS`。

版本说明：上游文字也举了 3300 欧姆的例子，但本包结构体的数值字段是整数，旧参考实现会在升单位时做整数除法；现有测试不覆盖 3.3 千欧这类结果。本次仅翻译，不改变该接口或测试。先完成测试覆盖的整数单位换算，不把旧实现的截断行为用于真实电阻测量。

## 提示

- 先组合前两位，再处理第三位的倍率。
- 注意中间结果的范围，不能因为返回字段较小就让中间计算溢出。
- 处理 0 时，应避免反复除以 1000 导致循环无法结束。
