# 基础课程合集

由旧 content/ 无损导出。ID 不变，旧进度继续适用。

当前为本地可编辑来源，不是已审核的公开发布包。原创题干与代码使用 MIT，全文见 licenses/MIT.txt。

共 198 题，以基础为主、进阶为辅：27 道编程题、69 道选择题、53 道判断题、49 道填空题。27 道编程题的参考实现位于各 lessons/<题目 ID>/reference/，供维护者审核和 CI 验证；开始练习时只复制 starter/，不会直接给出参考答案。

提交到 main 后，由 GitHub Actions 在无网络、低权限、有限资源的 Docker 容器中逐题验证：参考答案必须通过，起始代码必须编译成功且测试不通过。机器验证不等于人工内容及版权审核；只有对同一内容指纹完成审核后，才能进入 knowledge/approved 并发布。

本首发候选不包含第三方导入草稿，不需要开发板或 ROS 2 安装。硬件和 ROS 2 相关编程题使用纯 C/C++ 模型，不能代替真实硬件或 ROS 2 联调。
