# 课程包

当前课程按能力领域组织：

- `c-basics`：C 语言、内存模型和底层表达能力。
- `cpp-basics`：适合嵌入式场景的现代 C++。
- `embedded`：外设、状态机、通信和实时系统基础。
- `smart-car`：传感、控制、路径处理和车辆工程。
- `electronic-design`：测量、信号处理、控制和系统综合。
- `linux-basics`：路径、文件、权限、Bash、环境变量和进程基础。
- `ros2-basics`：节点、通信接口、参数、工作空间和机器人软件基础。

课程目录是只读来源。编程题使用独立的 `lesson.json`、初始代码和测试；选择题、判断题与填空题可集中存放在 `question-bank.json`。插件会按题型分类显示。

当前共 198 题：C 语言基础 62 题；C++、嵌入式、智能车和电子设计四个方向各 18 题；Linux 和 ROS 2 两个方向各 32 题。全部课程只有入门和进阶两个难度层级。

Linux、ROS 2 知识题使用 `language: "text"`，插件显示为“基础知识”，不需要安装对应系统或运行时。配套编程题仍使用 `c`/`cpp`，是本机可运行的教学模型，不是实际的系统命令评测或 ROS 2 节点集成测试。

编程题使用 `trainer start <id>` 将初始代码复制到根目录 `exercises/` 后作答，客观题则直接在 VS Code 课程面板提交。新增课程请阅读 `docs/adding-a-lesson.md`。
