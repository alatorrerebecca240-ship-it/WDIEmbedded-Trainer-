# 有序数组二分查找

在已排序数组中反复缩小查找区间，返回目标元素的位置。

知识点：数组、指针、二分查找、边界条件

## 题目背景

一组音乐家把喜欢的数字写成歌曲，并按数字标题排序。要在这份有序歌单中寻找指定数字，可以每次排除一半候选，而不必从头逐个比较。

## 题目要求

实现 `const int *binary_search(int value, const int *arr, size_t length)`。在长度为 `length` 的有序数组 `arr` 中查找 `value`：找到时返回指向数组中该元素的指针，未找到时返回空指针。二分查找的前提是数组已经排好序。

1. 取当前候选区间的中间元素。
2. 如果中间元素等于目标，查找完成。
3. 如果中间元素大于目标，排除它以及它右边的元素。
4. 如果中间元素小于目标，排除它以及它左边的元素。
5. 对剩余区间重复上述过程。区间为空时说明目标不存在。

## 示例

在 `[4, 8, 12, 16, 23, 28, 32]` 中查找 23。先比较中间的 16，保留右半部分 `[23, 28, 32]`；再比较 28，保留 `[23]`，最后找到目标。

## 提示

- 明确区间端点是否包含在查找范围内，不要混用两种约定。
- 空数组、单元素数组和目标不在数组中都需要正确结束。
- `size_t` 是无符号类型，减少下标时要避免从 0 下溢。
