# 反转字符串

将字符串中的字符顺序反转，并返回新的字符串。

知识点：字符串、迭代器、循环、边界条件

## 题目要求

实现 `reverse_string::reverse_string(const std::string& text)`。输入从左到右的顺序应变成从右到左，不改变字符本身的大小写或内容。

本包以测试中的普通英文文本为练习范围，不要求实现 Unicode 字素级反转；不要将逐字节反转直接当作处理中文和表情的通用方案。

## 示例

- `stressed` → `desserts`。
- `strops` → `sports`。
- `racecar` → `racecar`。
- 空字符串仍返回空字符串。

## 提示

- 可以使用反向迭代器，也可以先复制后交换首尾字符。
- 输入是常量引用，不应直接修改。
- 处理空字符串时，注意 `size() - 1` 的无符号下溢问题。
