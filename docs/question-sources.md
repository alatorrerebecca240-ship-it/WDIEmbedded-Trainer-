# 题目来源登记

0.6.0 的机器可校验来源与批量获取/转换流程见 [知识包工作流](knowledge-pack-workflow.md)。新包使用 `self-authored`、`imported`、`adapted`、`generated`；下面的旧来源分类是早期编辑建议，不是新发布协议的枚举。单纯外链不是可重新打包分发的题目授权。

题目进入仓库前必须选择一种模式：

- `self-authored`：自行命题、编写测试和答案。
- `derived`：从比赛能力点或厂商例程抽象出新题，记录来源。
- `licensed-copy`：许可证明确允许复制和修改，同时保留声明。
- `external-link`：只保存标题、标签和原网页链接。

不要把“网页可以访问”理解为“内容可以重新发布”。导入时至少记录来源 URL、许可证、题面是否允许保存、测试是否自行编写。厂商 SDK 往往在同一仓库中包含多种许可证，应检查具体文件而不是只看仓库名称。
