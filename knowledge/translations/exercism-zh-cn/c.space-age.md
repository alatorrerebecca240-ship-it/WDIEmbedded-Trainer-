# 换算行星年龄

给定经过的秒数，按不同行星的公转周期计算年龄。

知识点：枚举、浮点数、单位换算

## 题目要求

不同星球的一年长短不同。本题规定一个地球年为 365.25 天，即 `31557600` 秒。实现 `float age(planet_t planet, int64_t seconds)`，返回以指定行星年为单位的年龄。

| 行星 | 枚举 | 公转周期（地球年） |
| --- | --- | --- |
| 水星 | MERCURY | 0.2408467 |
| 金星 | VENUS | 0.61519726 |
| 地球 | EARTH | 1.0 |
| 火星 | MARS | 1.8808158 |
| 木星 | JUPITER | 11.862615 |
| 土星 | SATURN | 29.447498 |
| 天王星 | URANUS | 84.016846 |
| 海王星 | NEPTUNE | 164.79132 |

这是练习使用的固定参数，不需要查询天文数据或自行换成其他年长。

## 示例

`1000000000` 秒约为 `31.69` 地球年。计算时保留浮点精度，不必将结果预先格式化为只有两位小数的字符串。

## 提示

- 先求指定行星一年对应的秒数，再做除法。
- 避免先进行整数除法而损失小数部分。
- 检查测试对无效行星枚举的返回值约定。
