# 权限数字转 rwx

这是标准 C 的字符串练习，不调用 chmod，也不修改文件权限；Windows、Linux、macOS 均可用现有 C 编译器练习。

## 要求

实现 `int permission_triplet(unsigned digit, char output[4])`。

- output 保证指向至少 4 字节的可写空间，不会为空指针。
- digit 在 0～7 时：按 r、w、x 顺序写入三个字符，未设置的位用 '-' 表示，最后写入 '\0'，返回 0。
- digit 大于 7 时：返回 -1，output 的内容必须保持不变。
- r=4、w=2、x=1；只转换一组权限，不处理所有者/组/其他人的完整模式。
- 不要添加 main，也不要修改头文件或测试。

## 示例

| digit | 文本 | 返回值 |
| --- | --- | --- |
| 0 | --- | 0 |
| 4 | r-- | 0 |
| 6 | rw- | 0 |
| 7 | rwx | 0 |
| 8 | 保持原样 | -1 |

测试覆盖所有合法数字、非法数字与缓冲区边界。
