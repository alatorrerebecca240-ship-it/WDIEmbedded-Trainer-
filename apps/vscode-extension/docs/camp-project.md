# 阶段项目：模拟智能车控制台

这是训练路线的综合实践指南，不是自动评分题。先用电脑完成，不需要连接开发板或真实电机。

## 目标

编写一个 C 语言程序，读取你准备的传感器样本，根据设备状态计算并打印受限的控制输出。可以复用自己在数组、结构体、位操作、消抖、位置估计与限幅题中写出的实现。

建议在当前项目中自行建立 `camp-project/`，不要把项目代码写进题库源码或覆盖 `exercises/` 中的旧练习。

## 从最小版本开始

1. 输入层：先用数组存放左、中、右三路传感器的模拟数据，明确数值范围和标定约定。
2. 计算层：根据题目中学到的位置估计方法计算偏差；不要假定所有传感器都采用同一电平或黑白方向。
3. 输出层：先使用自己能够解释的简单控制规则，再将输出限制在你规定的区间。暂时不要求 PID。
4. 状态层：加入停止与运行状态；停止状态输出为零。为无效输入制定明确的处理规则。
5. 组织代码：把公共声明、数据处理与主程序分开，写一份构建和运行说明。

函数名、文件结构和限制区间由你设计。路线页面的示例是概念草图，不是可直接调用的现成 API。

## 最少完成这些检查

- 居中、偏左、偏右三种输入，输出方向符合你声明的约定。
- 输出过大时能限幅；停止状态不会继续输出非零控制量。
- 全部传感器无有效信号时，程序采取你说明的安全处理方式。
- 相同输入多次运行结果一致；数组访问与指针目标有效。
- 修改一个参数或换一组输入后，你仍能先预测结果，再运行解释差异。

将输入、预期结果和实际结果写成表格。不以“成功编译”代替行为检查。

## 给带教同学的交付物

交付源码、简短 README、至少三组输入输出记录，以及插件导出的学习报告。报告只记录题目成绩和你的自查文字，不会自动收集项目源码。

讲解时回答：数据从哪里来？每个函数负责什么？最重要的边界是什么？遇到过什么错误？还有什么不能解释？

插件中的“自查完成”由学习者勾选，不代表项目测试已经自动执行，也不代表带教同学验收通过。带教人员需要独立查看代码和演示。
