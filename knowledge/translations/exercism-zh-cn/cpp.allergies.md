# 用位标记查询过敏项目

解析一个整数中的二进制标志位，查询单项过敏情况及完整列表。

知识点：位运算、集合、常量、无符号整数

## 题目要求

本题将若干过敏项目编码为整数，仅作为编程模型，不是医学检测方法。每个项目占据一个二进制位：

| 中文名称 | 程序中的名称 | 分值 |
| --- | --- | --- |
| 鸡蛋 | `eggs` | 1 |
| 花生 | `peanuts` | 2 |
| 贝类 | `shellfish` | 4 |
| 草莓 | `strawberries` | 8 |
| 番茄 | `tomatoes` | 16 |
| 巧克力 | `chocolate` | 32 |
| 花粉 | `pollen` | 64 |
| 猫 | `cats` | 128 |

构造 `allergies::allergy_test` 对象后，`is_allergic_to` 查询指定项目，`get_allergies` 返回 `std::unordered_set<std::string>`。返回的字符串必须使用表中的英文名称。

分值是各项目分值的组合。例如 `34 = 2 + 32`，表示花生和巧克力过敏。256、512、1024 等未列出的高位必须忽略；257 只报告 `eggs`。

## C++ 接口说明

`unordered_set` 是不要求排序、元素不重复的集合，可使用 `insert` 或 `emplace` 添加元素。`const` 表示不允许修改；`unsigned int` 不能表示负数。

## 提示

- 每个已知项目的分值都是 2 的幂，可用按位与检查。
- 不要将总分与单个项目分值直接比较是否相等。
- 只遍历表中八个已知项目，就能自然忽略未知高位。
