# 按因数转换文本

根据一个数能否被 3、5、7 整除，把它转换成约定的雨滴声音。

知识点：条件分支、取余、字符串

## 题目要求

实现 `void convert(char result[], int drops)`，将结果写入调用者提供的字符数组。

- 能被 3 整除，追加 `Pling`。
- 能被 5 整除，追加 `Plang`。
- 能被 7 整除，追加 `Plong`。
- 如果 3、5、7 都不能整除它，就写入这个数的十进制字符串。

可能同时满足多个条件，追加顺序必须是 3、5、7 对应的顺序。声音字符串是测试接口约定，不要翻译、改变大小写或加入额外空格。

## 示例

| 输入 | 说明 | 结果 |
| --- | --- | --- |
| 28 | 只能被 7 整除 | `Plong` |
| 30 | 能被 3 和 5 整除 | `PlingPlang` |
| 34 | 三个条件都不满足 | `34` |

## 提示

- 这三个整除条件不是互斥条件，不能只保留第一个满足的分支。
- 只有完全没有追加声音时，才需要写入数字文本。
- 结果是 C 字符串，别忘记结尾的空字符。
