# 随机生成角色属性

模拟掷骰子，生成龙与地下城角色的六项属性和初始生命值。

知识点：数组、随机数、条件分支、向下取整

## 题目背景

朋友们准备第一次玩龙与地下城，但忘了带骰子。请编写程序模拟六面骰子，按规则创建角色。

## 题目要求

角色有力量 `strength`、敏捷 `dexterity`、体质 `constitution`、智力 `intelligence`、感知 `wisdom` 和魅力 `charisma` 六项属性。每项属性都独立掷四个六面骰子，每个骰子取 1 至 6，去掉其中一个最小值，将其余三个相加。重复六次，得到全部属性。

体质调整值的计算方式是 `(体质 - 10) / 2`，结果必须向下取整。初始生命值 `hitpoints` 等于 `10 + 体质调整值`。

实现 `ability()` 生成一次属性值、`modifier(int score)` 计算调整值，以及 `make_dnd_character()` 返回完整角色结构体。负数的向下取整与 C 的整数除法向零截断不同，不要混淆。

## 示例

| 四个骰子 | 去掉一个最小值后求和 | 属性 |
| --- | --- | --- |
| 5、3、1、6 | 14 | 力量 |
| 3、2、5、3 | 11 | 敏捷 |
| 1、1、1、1 | 3 | 体质 |
| 2、1、6、6 | 14 | 智力 |
| 3、5、3、4 | 12 | 感知 |
| 6、6、6、6 | 18 | 魅力 |

这个角色的体质为 3，调整值为 -4，生命值为 6。随机生成时不要求复现表中的固定点数。

## 提示

- 一次属性值只能在 3 至 18 之间，去掉的是一个最小骰子，不是所有并列最小值。
- 单独检查 score 为 3、9、10、11 时的调整值。
- 先完成一次属性生成，再组装六项属性和生命值。
