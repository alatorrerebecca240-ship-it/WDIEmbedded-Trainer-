# 电阻色环编码

建立电阻颜色与数字的对应关系，并按编码顺序列出全部颜色。

知识点：枚举、数组、查表

## 题目背景

电阻体积很小，直接印出阻值可能不便阅读，因此常用色环表示数字。请编写一个查询工具，避免使用者记忆每种颜色的编码。

## 题目要求

实现 `color_code(resistor_band_t color)` 返回指定颜色对应的数值，以及 `colors(void)` 返回按照编码顺序排列的颜色列表。

| 颜色 | 枚举名 | 编码 |
| --- | --- | --- |
| 黑 | `BLACK` | 0 |
| 棕 | `BROWN` | 1 |
| 红 | `RED` | 2 |
| 橙 | `ORANGE` | 3 |
| 黄 | `YELLOW` | 4 |
| 绿 | `GREEN` | 5 |
| 蓝 | `BLUE` | 6 |
| 紫 | `VIOLET` | 7 |
| 灰 | `GREY` | 8 |
| 白 | `WHITE` | 9 |

这里只处理颜色对应的数字，不需要计算倍率或电阻误差。例如红色对应 2。代码中的枚举名称必须与头文件一致。

## 提示

- 仔细查看枚举的已有定义，理解枚举值与数字的关系。
- 返回的颜色列表必须按黑、棕、红一直到白的顺序排列。
- 返回指针时，不要让它指向函数返回后已经失效的局部数组。
