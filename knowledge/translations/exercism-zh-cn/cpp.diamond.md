# 绘制字母菱形

输入一个大写字母，生成以 A 为顶点、输入字母为最宽行的对称菱形。

知识点：字符串、二维图形、循环、对称性

## 题目要求

实现 `diamond::rows(char middle_letter)`，返回每一行组成的 `std::vector<std::string>`。

- 首行和末行各有一个 `A`；其他行恰好有两个相同字母。
- 上半部分字母递增，下半部分递减。
- 图案上下对称、左右对称，整体宽度等于高度。
- 每行的前导空格与尾随空格数量相同，可能为 0；不要省略尾随空格。

## 示例

以下用 `·` 显示空格，实际结果中必须使用普通空格，不是圆点。

输入 `A`：

```text
A
```

输入 `C`：

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

输入 `E` 时宽、高均为 9，中间行为 `E·······E`。

## 提示

- 先计算总宽度，再用空格初始化每一行。
- 根据当前字母离 A 的距离，确定左右两个字母的位置。
- 可先生成上半部分与中间行，再镜像补齐下半部分。
